## How to use this log

- Link each member to the slices, AI interactions, decisions, fixes and integration work they actually did. D4 says "contributions are verifiable", so add references (Workflow Evidence Log row numbers, commits, chat references).
- Fill it in as work happens. Don't write it from memory at the end.
- Every member must be able to explain the whole product, the architecture, the plan and the major decisions. Individual marks may differ where contribution or understanding differs.
- Leave cells empty until there is something real to record.
